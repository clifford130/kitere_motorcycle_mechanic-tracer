# Kenya Vehicle Mechanic Tracer

A general system for connecting vehicle owners with trusted mechanics in Kenya.

## Intelligence Module
The system now includes an AI-powered Intelligence Module that:
- Analyzes vehicle symptoms entered by users.
- Maps symptoms to specific repair services using a keyword-based classifier.
- Recommends the best mechanics based on service match, distance, rating, and experience.
- Checks real-time availability for booking.

The module is implemented in Python using FastAPI and is integrated with the PHP frontend.
